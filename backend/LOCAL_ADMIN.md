# Администратор локальной демонстрации

Для локального сервера с `VECTOR_ENVIRONMENT=development`:

```sh
docker compose exec api python -m app.commands.demo_admin
```

В приложении: логин `admin`, пароль `admin`. Команда создаёт отдельный аккаунт
`admin@vector.example` с ролью `admin` и подтверждённым email. Повторный запуск
не сбрасывает пароль и не разблокирует существующего пользователя.

Администратор видит заявки работодателей и учреждений образования и может
одобрять их через раздел организаций. Заявки ожидающих подтверждения email
пользователей не появляются в очереди до подтверждения адреса.

Демонстрационный вход отключён вне development. Для настоящего администратора
используйте `python -m app.commands.create_admin` и отдельные email и пароль.
Демонстрационная команда никогда не запускается автоматически при старте сервера.
