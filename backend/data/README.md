## Импорт 9 ноября 2026

`passing_scores.grsu.2026.json` — 122 записи для существующих связей каталога ГрГУ. Источники:

- [Дневная форма, 2026](https://abit.grsu.by/view/272-kategorii-ru/vysshee/itogi-priema-proshlykh-let/2025/1794-prokhodnoj-ball-po-spetsialnostyam-2026.html).
- [Заочная форма, 2026](https://abit.grsu.by/view/272-kategorii-ru/vysshee/itogi-priema-proshlykh-let/2025/1795-2026-prokhodnye-bally-zaochnaya.html).

Год взят из заголовка и таблицы: сегмент `/2025/` в URL не является годом этих данных. Бюджет/платное и полный/сокращённый срок различены. Дробные баллы не округляются. Код связывается только при единственности и в таблице источника, и в каталоге этого учреждения. Неоднозначные профили по одному коду пропущены; «без вступительных испытаний» не превращается в ноль. Причины пропуска — в `passing_scores.grsu.2026.report.json`.

Подготовка JSON из сохранённых HTML и выгрузки id/name/code специальностей: `python -m app.scripts.prepare_grsu_scores CATALOG_JSON DAY_HTML PARTTIME_HTML OUTPUT_JSON`. Это инструмент для уже проверенных таблиц, а не автоматическая верификация любого сайта.

Импорт из backend:

```sh
docker compose cp data/passing_scores.grsu.2026.json api:/tmp/grsu.json
docker compose exec -T api python -m app.scripts.import_passing_scores /tmp/grsu.json
```

`contacts.verified.2026-11-09.json` — отдельно проверенные поля контактов ГрГУ и БГАА с ссылками. Повторяемый импорт: `python -m app.scripts.import_verified_contacts PATH --apply`; без `--apply` выполняется только предварительный просмотр. Полная запись учреждения не считается проверенной только потому, что сверены телефоны. Более свежий набор и отчёт о пробелах описаны в `../AI_CATALOG.md`.

`catalog_missing_contacts.2026-11-09.csv` — список оставшихся пустых полей, не перечень несуществующих контактов. Общая почта учреждения не переносилась в admissions_email без основания считать её почтой приёмной комиссии.

Извлечение ранее сохранённых контактов: `python -m app.scripts.enrich_catalog_contacts` показывает изменения; `--apply` применяет только к пустым полям. Сохраняются ссылки исходных записей, дата исходных данных, внесённые значения. Поля не получают отметку актуальной проверки. Повторное применение после успешного импорта не меняет данные.

Историческое состояние после этого импорта: 344 учреждения, 879 специальностей и 144 записи
баллов. Текущие цифры всегда берите из самого свежего каталога `audit.YYYY-MM-DD`.
