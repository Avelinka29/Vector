# Отправка писем через Gmail API

Google-вход пользователей и разрешение на отправку писем — отдельные настройки.
Для писем авторизуется только владелец почты отправителя. Firebase не используется.

1. В Google Cloud включить Gmail API в проекте VECTOR.
2. В Google Auth Platform → Audience добавить почту отправителя в Test users,
   если приложение находится в режиме Testing.
3. В Data Access добавить только `https://www.googleapis.com/auth/gmail.send`.
4. В Clients создать отдельный OAuth client типа **Desktop app**, например
   `VECTOR Mail Setup`. Не изменять iOS-клиент Google-входа.
5. Скачать OAuth JSON и сохранить вне репозитория. Не присылать его содержимое в чат.
6. Из каталога backend выполнить:

```sh
.venv/bin/python -m pip install -e '.[dev]'
.venv/bin/python -m app.scripts.connect_gmail /путь/к/client.json --sender ваша@gmail.com
```

В браузере выбрать именно почту отправителя и подтвердить отправку писем.
Скрипт сохраняет OAuth-настройки в локальный `.env`, не выводит секреты и не отправляет письма.
После этого пересоздать API: `docker compose up -d --build api`.

В режиме Testing refresh token для Gmail обычно действует 7 дней. Перед постоянным
использованием настроить publishing status и проверить требования Google к OAuth-приложению.

## Проверка восстановления

В приложении ввести email своего тестового аккаунта и нажать «Забыли пароль?».
Открыть ссылку из письма. Если почтовый клиент не открывает `vector://`, скопировать
полную ссылку и вставить через «Уже есть ссылка для сброса пароля» на экране входа.
Задать новый пароль и войти. Повторное использование и истечение срока ссылки
должны давать ошибку. Срок ссылки — 30 минут.

Один транспорт используется для писем подтверждения/восстановления из auth API и очереди
писем учреждений. При `VECTOR_EMAIL_TRANSPORT=gmail` SMTP для них не требуется.
Очередь повторяет неудачные отправки и помечает письмо отправленным только после ответа провайдера.
Письмо подтверждения учреждения содержит также ссылку открытия в iOS-приложении.

Документация: https://developers.google.com/workspace/gmail/api/guides/sending
и https://developers.google.com/identity/protocols/oauth2
