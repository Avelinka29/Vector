# Помощник и справочник: проверка 12 ноября 2026

Помощник сохраняет историю и карточки источников. Поиск понимает сокращения вузов
(включая ГрГУ, БГУ и БГУИР), ограничивает специальности выбранными учреждениями
и исключает неопубликованные организации. Баллы связаны с учреждением,
специальностью и годом. При недоступности модели явно показываются результаты
поиска по справочнику. Неудачную загрузку истории можно повторить.

Для модели Docker Compose принимает `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`,
`OPENROUTER_BASE_URL` и `OPENROUTER_APP_NAME` из локального окружения. Секреты
не входят в репозиторий. Проверены ответ действующей модели и запрос к PostgreSQL.

`data/contacts.verified.2026-11-12.json` содержит контакты БГУИР, БГЭУ, БГМУ
и Новогрудского торгово-экономического колледжа: 24 поля в шести карточках.
Источники и даты указаны в файле. Импорт сохраняет прежние значения и не
помечает всё учреждение проверенным:

```sh
python -m app.scripts.import_verified_contacts PATH           # предварительный просмотр
python -m app.scripts.import_verified_contacts PATH --apply   # применение
python -m app.scripts.audit_catalog OUTPUT_DIRECTORY
```

Отчёт `data/audit.2026-11-12/` фиксирует 344 учреждения и 879 специальностей.
Пусты 47 адресов, 67 телефонов приёмных комиссий, 323 email приёмных комиссий
и 64 сайта. Это перечень пробелов, а не утверждение об отсутствии контактов.
Полный каталог школ и полная проверка всех карточек не завершены.

Миграции 0012 и 0014 сохранены как необходимые звенья уже применённой
линейной цепочки; их существующую историю не переписывали.
