# VECTOR

Мобильное iOS-приложение VECTOR и отдельный backend на FastAPI/PostgreSQL.

## Локальный запуск

### 1. Запустить backend

```bash
cd /Users/avelinamaksimchik/Desktop/projects/Vector/program/Vector/backend
docker compose up -d --build
```

Адреса локальных сервисов VECTOR:

- API: `http://localhost:8002`
- документация API: `http://localhost:8002/docs`
- проверка сервера: `http://localhost:8002/health`
- Adminer: `http://localhost:8083`
- PostgreSQL с Mac: `localhost:5434`

Проверить состояние контейнеров:

```bash
docker compose ps
docker compose logs --tail=100 api
```

Успешная проверка API возвращает:

```json
{"status":"ok"}
```

### 2. Запустить приложение на iPhone

Локальный сервер работает на Mac, поэтому при разработке iPhone подключается к нему
по локальному IP-адресу Mac. Текущий адрес хранится в `Vector/Info.plist` в поле
`VECTOR_API_BASE_URL`.

На момент написания инструкции используется:

```text
http://192.168.100.215:8002
```

После изменения адреса в `Info.plist` приложение необходимо заново собрать и установить
на iPhone.

## Если изменилась сеть или IP Mac

Домашний роутер, точка доступа телефона и сеть колледжа могут назначать Mac разные
локальные IP-адреса. Это нормально: текущий адрес не является постоянным.

1. Узнать новый IP Mac:

```bash
ipconfig getifaddr en0
```

2. Подставить результат в `VECTOR_API_BASE_URL`, сохранив порт `8002`. Например:

```text
http://192.168.1.47:8002
```

3. Проверить сервер на самом Mac:

```bash
curl http://localhost:8002/health
curl http://192.168.1.47:8002/health
```

4. Пересобрать приложение в Xcode и снова запустить его на iPhone.

Телефон и Mac должны находиться в одной локальной сети. В общественной сети подключение
может не работать даже при одном Wi-Fi, если включена изоляция клиентов.

### VPN

VPN не мешает, если он разрешает доступ к локальной сети. Если приложение перестало
видеть сервер, временно отключить VPN и повторить проверку. Также проверить macOS Firewall
и разрешить Docker/Xcode принимать входящие подключения.

Для демонстрации наиболее предсказуемый вариант — подключить Mac к точке доступа iPhone.

### Постоянное решение

Локальный IP используется только для разработки. Для публикации backend нужно разместить
на сервере с постоянным HTTPS-адресом, например `https://api.vector.by`. Тогда Mac и Docker
не должны быть постоянно включены, а сеть iPhone не имеет значения.

## Почему вход может долго загружаться

После ввода пароля приложение выполняет несколько запросов: авторизацию, загрузку аккаунта,
профиля и данных роли. Если локальный IP недоступен, iOS ожидает сетевой тайм-аут.

Также ранее VECTOR и Spark использовали одинаковое имя Docker Compose-проекта `backend`.
Из-за этого на порту VECTOR мог отвечать сервер Spark. Конфликт устранён: VECTOR теперь
имеет имя Compose-проекта `vector-backend` и порт `8002`.

При проблеме проверить по порядку:

```bash
cd /Users/avelinamaksimchik/Desktop/projects/Vector/program/Vector/backend
docker compose ps
curl http://localhost:8002/health
curl http://$(ipconfig getifaddr en0):8002/health
```

Затем проверить значение `VECTOR_API_BASE_URL` и заново установить приложение.
