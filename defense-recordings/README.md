# Записи экрана для защиты

Запись выполняет ассистент, а не пользователь. Видео сохраняются в этой папке и исключены из Git; сценарий хранится в `../DEFENSE_DEMO_RU.md`.

- `01-auth-interface.mov` — 92 секунды, реальная запись симулятора iPhone 17: три роли регистрации, вход, проверка пустого email, форма нового пароля, возврат ко входу. Это обзор интерфейса, не доказательство отправки письма или успешного сброса.

Первый файл записан 9 ноября 2026 через simctl, H.264. Учебный профиль для дальнейших фрагментов содержит вымышленные данные. Видео пока без озвучки; перед финальной сборкой нужно обрезать паузы между действиями.
