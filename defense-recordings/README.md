# Записи экрана для защиты

Запись выполняет ассистент, а не пользователь. Видео сохраняются в этой папке и исключены из Git; сценарий хранится в `../DEFENSE_DEMO_RU.md`.

- `01-auth-interface.mov` — 92 секунды, реальная запись симулятора iPhone 17: три роли регистрации, вход, проверка пустого email, форма нового пароля, возврат ко входу. Это обзор интерфейса, не доказательство отправки письма или успешного сброса.
- `02-applicant.mov` — 130 секунд: главный экран учебного профиля, справочник и карточка учреждения, профиль, цифровая анкета, вопрос и ответ помощника. Это черновой дубль: ответ на сокращение «ГрГУ» не нашёл имеющиеся направления и не показал карточки источников. В поиске помощника отсутствует этот псевдоним; требуется исправление поиска и повторная запись AI-сценария. Не использовать этот ответ как демонстрацию корректного подбора.
- `03-document-ocr-error.mov` — диагностическая видеозапись выбора учебного аттестата: файл выбран локально, но Vision сообщил ошибку распознавания. Закрытие редактора без завершения анкеты не сохранило вложение в профиль. Это не успешная демонстрация OCR или серверной загрузки.
- `04-document-success.mov` — успешный повтор после исправления: выбор аттестата, распознавание текста и совпадения ФИО, завершение шагов анкеты, сохранение и повторное открытие обзора документов с отметкой «Сохранён локально». Это локальный документ, не серверное вложение заявления. Перезапуск приложения в этом дубле не проверялся.

Причина ошибки третьего дубля подтверждена отдельным запуском Vision: поиск лица возвращал Code 9 «Could not create inference context» на симуляторе, а распознавание текста работало. Коммит `90424b8` исключает поиск лица для аттестата и других текстовых документов. Сборка прошла; сервис вернул `likelyMatches`; четвёртый ролик подтверждает результат в интерфейсе. Паспорт и портрет по-прежнему требуют отдельной проверки на устройстве.

Первый файл записан 9 ноября 2026 через simctl, H.264. Учебный профиль для дальнейших фрагментов содержит вымышленные данные. Видео пока без озвучки; перед финальной сборкой нужно обрезать паузы между действиями.

С 10 ноября использовать `record_simulator.py UUID output.mov --seconds 120`: автоматическая остановка предотвращает длительную запись неподвижного экрана после прерывания агента. Прерванный большой черновик от 9 ноября удалён; завершённые ролики сохранены.
