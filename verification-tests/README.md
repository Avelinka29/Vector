# Проверка сопоставления документов

`Sources/DocumentVerificationCore/DocumentVerificationCore.swift` — символическая
ссылка на тот же исходник, который собирает iOS-приложение. Копии алгоритма нет.

Запуск: `swift test --package-path verification-tests`.

Swift Testing проверяет совпадение/несовпадение имени и фамилии для паспорта,
аттестата и сертификата, транслитерацию и MRZ, целые слова вместо подстрок,
отсутствие лица, разрешение, номер паспорта и цифровую дату рождения.
Используются только вымышленные данные. Эти проверки не заменяют запуск Vision
на фотографиях и устройстве.
